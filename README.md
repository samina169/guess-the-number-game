# Number Guessing Game

A simple number guessing game built with Python and Streamlit.

## How to Play
1. The computer will randomly select a number between 1 and 100
2. Enter your guess in the input field
3. You'll get feedback if your guess is too high or too low
4. Try to guess the number in as few attempts as possible!

## Setup and Running
1. Install the required dependencies:
```bash
pip install -r requirements.txt
```

2. Run the game:
```bash
streamlit run app.py
```

The game will open in your default web browser.
